## MTG: the quarantine hid a fixable defect, and it is now fixed

The report quarantined MTG because the frozen roster assigns MGIC to `reinsurance` while it
writes private mortgage insurance. Correct observation, wrong remedy — the payload still
carried MTG with five claims and a judgement written in reinsurance language: *treaty and
line*, *retrocession cost*, *ILS capacity*, *rate-on-line*. None of that exists at MGIC.

Root cause: the book files MTG under GICS "Reinsurance", and `INDUSTRY_OVERRIDES` already
routed ACT, ESNT and NMIH to `private_mortgage_insurance` — **MTG, the largest of the four,
was missing from its own peer group.** Fixed in `clab/external/taxonomy.py` with a named
test. The unit is now ACT/ESNT/MTG/NMIH, and `reinsurance` is EG/RGA/RNR/SPNT, which is also
the right comparison set for the other three.

## What this establishes

A batch can pass every gate the pipeline has and still be worse than its predecessor, because
no gate compares a batch to the last one. The acceptance command specified in
`docs/PLAN_TO_1500_2026-09-11.md` must include **per-field fill versus the previous batch of
the same sector** and **evidence concentration**, and it must run before ingest. This batch is
the worked example of why, and it cost one research session rather than 42 company records,
which is the cheapest this lesson has ever been bought here.
